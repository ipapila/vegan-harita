GitHub Ayarları

Buraya girdiğiniz bilgiler yalnızca bu tarayıcıda saklanır. Bağlantı kurulduğunda "Manuel Mekan Ekle", "JSON İçe Aktar" ve mekan düzenlemeleri otomatik olarak GitHub deponuza commit edilir ve tüm cihazlarda görünür olur.

Sadece bu repo için "Contents: Read and write" izniyle oluşturulmuş fine-grained bir token kullanın (Settings → Developer settings → Fine-grained tokens). Token bu tarayıcının localStorage'ında düz metin olarak saklanır — bu cihazı başkalarıyla paylaşmayın ve token'ı sadece bu iş için, süresi sınırlı olarak oluşturun.

👥 Üyeler

Siteye kayıt olan üyelerin listesi. Bu bilgilere yalnızca admin, aşağıya girdiği Supabase Service Role anahtarıyla ulaşabilir.

Supabase projenizde Project Settings → API → "service_role" anahtarını buraya girin. Bu anahtar tüm üye kayıtlarına erişim sağlar; yalnızca bu tarayıcının localStorage'ında saklanır, kimseyle paylaşmayın.
